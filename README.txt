RED LEGACY — GitHub Pages upload version

NO npm. NO terminal. NO build step.

1. Create a GitHub repository.
2. Open Add file -> Upload files.
3. Upload index.html and the videos folder.
4. Commit changes.
5. Repository Settings -> Pages.
6. Under Build and deployment choose Deploy from a branch.
7. Select main and / (root), then Save.
8. GitHub will give you the live website address.

For the Top 10 video page, put licensed MP4 files in videos/ using:
penalty-01.mp4
...
penalty-10.mp4

IMPORTANT: only upload footage and photographs you have the right/licence to use.
This is an unofficial fan project.
